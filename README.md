# Andy AI 咨询页

面向 `https://ai.flowher.cn/` 的静态网页。首屏为 20 秒自动循环的 WebGL 城市镜头，后续为六屏静态信息；下滑时城市展开到两侧，继续滚动时镜头随之前进或后退。

## 本地预览

在当前目录启动任意静态文件服务器，然后访问根路径即可。

## 城市与交互

- Three.js 0.186.1 与平面反射模块保存在 assets/vendor，许可证随文件保留；无需外部 CDN 或后端。
- 广告屏固定在三栋楼的外墙，镜头沿弧线朝下一块广告牌飞行，在文字前放缓掠过。三块广告使用接近的阅读窗口，广告之间的飞行加快；第 14–16 秒以城市全景显示 ANDY，下滑按钮上移、放大并变形，完整停留两秒，再平滑回到起点。
- 三块广告牌分别使用同一 Andy 卡通形象的产品展示、侧身操作和庆祝动作。人物与文字一同绘制在楼体屏幕上，素材来源和生成提示词见 docs/andy-billboard-assets.md。
- 网页使用 960×960 透明 WebP 人物图，每张约 118–155 KB，比原始 PNG 小约九成；头部以高优先级预加载三张。动画不等待人物下载，图片完成后绘入广告牌。原始 PNG 保留为素材源。
- 动画开始前预热场景与后处理着色器；保留 HDR 场景抗锯齿，取消最终整屏合成的重复抗锯齿，并限制大窗口的渲染像素预算。遇到浏览器长任务时限制单帧时间步长，避免镜头突然跳远。
- 阶梯式、连体式、斜撑式、圆弧塔与扭转塔形成不同轮廓；稀疏窗灯、湿润路面倒影、楼顶与地面旋转霓虹射灯和道路交通补充城市层次。
- `city-world.js` 构建场景及光效，`city-flight.js` 定义周期航线与沿航线转向，`city.js` 管理自动播放与滚动。横竖屏共用物理路径，每种尺寸的视野在整轮中保持固定。
- 可暂停、重播；支持减少动态效果及 WebGL 不可用时的静态回退。
- 使用浏览器原生滚动与锚点，长内容不会被强制裁成一屏。
- 设计约束见 docs/city-design.md。

## 本地验证

运行 `node --test tests/city-flight.test.mjs` 检查运镜在各段及循环边界的速度、加速度和 jerk 连续性、沿实际路径转向、竖屏阅读时长、视野固定、广告前持续运动及主楼碰撞。当前浏览器验收记录见 docs/city-qa.md。
