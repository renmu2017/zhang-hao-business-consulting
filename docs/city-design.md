# ANDY 城市开场与整屏网站

## 已确认的方向

- 本地设计实现完成；2026-09-30 用户确认录制演示视频并发布到 https://ai.flowher.cn/。
- 第一屏为循环播放的未来城市，楼体外墙的霓虹广告牌展示 AI 产品落地、Agent 与自动化、增长与商业化。
- 收尾只突出 ANDY，并保留“向下探索”。用户可随时下滑、暂停或重播。
- 后续页面使用现有事实与咨询内容，静态可读，支持滚动吸附。
- 用户反馈第一屏信息太密、字号太小后，个人介绍与详细经历拆为两屏。

## 内容与层级

1. 城市：20 秒一轮，连续飞行、三块楼体广告牌、升高拉远、第 14–16 秒 ANDY 全景停留两秒，再回到起点。广告前缓缓掠过，没有静止等待；循环首尾位置、朝向及运动变化连续。
2. 个人介绍：大标题、简短介绍、清华与 16 年/8 年经历、人物图、40 万粉/1 亿+/2 款月活过万的 ToC 产品。
3. 项目与成果：原有 ToB/ToC/增长经历、团队、专利与软著、奖项、专业成果。
4. 咨询方向：原有四个服务方向。
5. 咨询方式：现状、关键判断、下一步。
6. 咨询费用：¥780/30 分钟、¥1,480/60 分钟和长期合作。
7. 联系预约：原有邮箱、微信与预约说明。

## 实现约束

- 保留静态 HTML/CSS/JavaScript、GitHub Pages 路径、CNAME、结构化资料与联系方式。
- 唯一新增运行时依赖为本地托管 Three.js 0.186.1，保留 MIT 授权文件；城市几何程序生成，三张广告人物贴图本地托管，无需外部 CDN 或 API。
- 程序生成楼宇、窗户、城市光流与广告牌；固定镜头路径。下滑时城市展开到两侧，后续滚动映射为镜头的前进与后退；中间的静态阅读区域保持高对比。切换到后台停止自动渲染。
- 原生滚动与锚点导航；桌面使用整屏吸附，小屏/矮屏采用轻吸附。页面至少一屏，内容较长自然伸展。
- 用户开启减少动态效果时直接展示 ANDY 收尾静帧；WebGL 无法使用时展示 CSS 城市与 ANDY。
- 文字、按钮具有正常 HTML 语义、键盘焦点与跳过动画入口，画布装饰不进入无障碍阅读顺序。

## 本轮视觉重做

- 用户明确要求更精细的未来城市、缩短停留、自动播放及丝滑运镜；沿用已确认的城市与墙面广告方向，直接实现。
- 远、中、近景分别建立轮廓：阶梯高楼、扭转塔、连体塔与有支撑的高架拱桥；近景补足幕墙框架、楼层挑檐、设备、商铺与路灯。
- 深蓝玻璃、陶瓷板与金属作为主体，青色轮廓光搭配稀疏暖色室内光、少量紫色与金色标识；减少常规楼宇密度，避免全城相同方盒和均匀点阵窗户。
- 湿润道路保留真实倒影，加入路面材质、交通实体和立体光晕，画面中明确出现尺度与景深。
- 镜头位置用周期九阶 Bézier 曲线连接，位置的一至四阶导数连续；水平朝向跟随实际航线切线，转向的一至三阶导数连续。垂直视线单独稳定，爬升不带来突然仰俯。两段广告转场只沿目标方向转动；20 秒版本转向速度低于 33 度/秒。
- 横竖屏使用同一条实际航线；每种尺寸的镜头视野整轮保持固定，竖屏至少保留 38 度水平视野以容纳完整广告，不用动态变焦替代转向。镜头保持在城市街道上方，广告主楼与突出结构避碰。
- 竖屏第一幕提前完成进场，三块广告的主要阅读时长接近。广告上使用同一人的三种明显不同动作与视角，人物约占屏幕四分之一；文字优先，人物没有额外循环肢体动作。
- ANDY 使用街道轴线上的高位全景。扩展地面、九栋形态不同的远处轮廓楼和统一大气层过渡补足深度，避免露出城市边缘与大片空场；品牌展示时隐藏小型空中交通实体。下滑入口上移、放大和变形为横向发光按钮，与 ANDY 一同完整停留两秒。
- 三组楼顶、三组地面实体灯座配旋转霓虹射灯，光束、楼面照明与反射共同运动，光束采用柔和的边缘和距离衰减。
- 光束末端在参与非整数次幂前限制插值范围，并丢弃接近零透明度的端部，避免无效浮点值被 HDR 辉光放大成黑色像素环。
- 页面首次打开即播放，人物下载不阻塞起飞，图片完成后绘入广告牌。动画操作只是可选的暂停与重播。减少动态效果模式保留静帧。
- 简介保留“2 款 ToC 产品”标识，按用户 2026-10-02 确认展示“月活过万的两个 C 端产品”，不写产品名称；B 端项目统一为“1 亿+”。
- 人物原始素材保留，运行时使用约九成体积压缩的透明 WebP，并在 HTML 中提前加载。动画模块也在头部预加载，减少逐级模块发现的等待。着色器在起飞前预热，最终整屏合成不重复抗锯齿，大窗口限制渲染像素预算。浏览器出现长任务后单帧时间步长不超过 50 毫秒。
