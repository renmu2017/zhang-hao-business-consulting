# 城市动画本地验收

2026-09-30，29.95 秒自动循环版本，包含三种不同视角与动作的 Andy 广告人物。本记录覆盖发布前的本地实现与浏览器验收。

## 当前修改与证据

- 转场沿实际弧形航线转向。修复前竖屏相机的水平朝向与位移方向最大偏差约 64.64 度；当前误差小于 0.00001 度。上下仰俯单独稳定，不让爬升引发突然抬头。两段广告转向均单向变化，没有转过目标再摆回；数值采样的最大转向速度约 19.93 度/秒，最大位移加速度约 40.17 场景单位/秒²。
- 横竖屏使用相同物理航线，每种尺寸的 FOV 整轮固定；竖屏水平视野至少 38 度。相机在街道上方，未进入三栋广告主楼及其阶梯/双塔突出结构，手机开场未露出此前的地面边界。
- 第一幕进场由 2.30 秒缩短为 1.25 秒。390×844 的主要阅读窗口按广告区域投影估算，由约 4.69/3.80/4.60 秒变为 3.65/3.80/4.60 秒。新增回归检查在调整前失败，在当前实现通过；这些时长属于投影模型估算，实际画面另经整轮实录查看。
- 三张最终人物均有真实透明像素，尺寸 1254×1254，可正常解码。产品为正面原型展示；Agent 为左向侧面低头操作；增长为另一侧三分之四视角仰头抬拳。均绘入楼体广告屏右侧，标题与副标题保持可读。人物不添加额外循环动作。素材与完整提示词见 `andy-billboard-assets.md`。
- ANDY 高位全景使用扩展地面、统一大气过渡与九栋远处轮廓楼补足背景，保留正常夜空和景深，未露出城市的硬边界。全景机位完整固定两秒；下滑按钮同步上移、放大和变形，最终为 272×66 像素。手机矩形为 `[59,449.92,272,66]`，桌面为 `[584,523.61,272,66]`。
- 当前版本手机视口实录 32.46 秒、958 个原始画面；桌面实录 32.47 秒、967 个原始画面。两次均从轮次 0 进入 1，保持 `playback=playing`、`artwork=ready`。最终 MP4 按采样时间以 30 fps 编码，覆盖完整循环。
- 发布前另录制 1920×1080 横屏：959 个原始画面、32.45 秒，完整进入下一轮，ANDY 及变形入口有七个完整显示的 DOM 样本。交付 MP4 为 H.264、30 fps、32.50 秒，保存为 `/Users/admin/Public/ANDY-city-demo/ANDY-city-demo-1080p.mp4`。
- 当前版本暂停后时间保持 8.40 秒，重播恢复自动播放。真实点击下滑入口后旅程值为 1.000，进入咨询方向后为 3.032，返回简介后为 1.000。前进与后退均更新城市镜头。
- 桌面 1440×900、平板 820×1180、手机 390×844 均无横向溢出，简介中的“2 款 ToC 产品”及 FlowHer / DualFunCam 完整保留。平板减少动态效果模式显示 22.95 秒 ANDY 全景静帧，播放控制隐藏，人物贴图正常。检查后恢复常规播放和用户实际窗口尺寸。
- 正常浏览器错误及警告日志为空。11 项运镜回归检查通过：每个节点及循环边界的速度、加速度和 jerk 连续，广告阅读区仍在移动，水平朝向跟随真实航线，FOV 固定，竖屏时长平衡，ANDY 停留两秒，相机高度/城市边界/主楼避碰有效。命令：`node --test tests/city-flight.test.mjs`。
- JavaScript 语法与应用代码的 Git 空白检查通过；Three.js 的原始供应文件保留上游空白格式。无 WebGL 的 CSS 静态回退仅作源码检查，未在禁用 WebGL 的真实环境中验证。视口模拟与浏览器渲染指标不代表真实手机性能。
